# 모노폴리 무기 숙련도 재분배 룰렛

대상의 이름과 무기, 그 무기에 해당되는 숙련도를 넣어 대상 당 랜덤한 무기의 숙련도를 1씩 빼앗습니다.
빼앗은 무기 숙련도를 합산하여 캐릭터들에게 재분배를 하는 사이트입니다.

## 링크

[바로가기](https://gaseu-rangers.github.io/weapon_mastery_roulette/)

## 사용 방법
1. 이름과 무기, 숙련도를 각 표에 입력합니다.
2. 필요 시 '무기 추가' 또는 '대상 추가' 버튼을 통해 선택지를 추가합니다.
3. 룰렛 돌리기 버튼을 누릅니다.

- 숙련도가 0일 시 빼앗기는 대상에서 제외됩니다.
- 재분배 시, 0또는 최댓값을 받을 수 있습니다.
